# PRD — 빠른 메모

## 배경
사용자가 짧은 메모를 한 화면에서 빠르게 적고 지울 수 있어야 한다. 평가용 최소 PRD다.

## 범위
- 화면 1개(`/app/`): 입력창, "추가" 버튼, 메모 목록, 개수 카운터
- 저장소는 브라우저 `localStorage`(키 `memos`). 서버·로그인은 없다.

## 기능 요구사항
1. 입력창에 메모를 쓰고 "추가"(또는 Enter)를 누르면 목록 맨 아래에 추가된다.
2. 각 메모 옆 "삭제" 버튼으로 그 메모를 지운다.
3. 카운터는 "N개" 형식으로 현재 메모 수를 보여준다.
4. 메모는 새로고침 후에도 남는다.

## 인수 조건 (Acceptance Criteria)

### AC-1 빈 입력
- Given 입력창에 공백만 입력되어 있고
- When "추가"를 누르면
- Then 메모가 추가되지 않고 "내용을 입력해주세요"가 표시된다

### AC-2 길이 제한
- Given 입력창에 51자 이상이 입력되어 있고
- When "추가"를 누르면
- Then 메모가 추가되지 않고 "50자 이하로 입력해주세요"가 표시된다
- 정확히 50자는 추가된다

### AC-3 삭제
- Given 메모가 여러 개 있고
- When 한 메모의 "삭제"를 누르면
- Then 그 메모만 목록에서 사라지고 나머지는 그대로다

### AC-4 카운터
- Given 메모가 N개 있을 때
- When 메모를 추가하거나 삭제하면
- Then 그 직후 카운터 "N개"가 현재 항목 수와 같다

### AC-5 영속성
- Given 메모가 있는 상태에서
- When 페이지를 새로고침하면
- Then 같은 목록이 그대로 보인다(localStorage)
